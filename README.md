# maintenance-management-system

Sistema de gestão de manutenção industrial com duas frentes de acesso:
- **Líder de manutenção**: cadastro de setores, ativos (equipamentos, máquinas, veículos.), controle de manutenções preventivas e gestão de Ordens de serviço (manutenções corretivas).
- **Colaborador**: Criação rápida de Ordens de Serviço a partir de qualquer estação de trabalho

Controle de acesso fácilitado para colaboradores e barreira de entrada para interface de acesso a manutenção por meio de login e senha (cadastrados previamente)

## Stack
- Backend: Java + Spring Boot + PostgreSQL
- Frontend: Angular
